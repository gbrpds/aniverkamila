# 🎵 Música do site

O site tem um botão flutuante (canto inferior direito) que toca uma música.

## Como adicionar a música

1. Escolha a música (de preferência algo dos **anos 2000** pra combinar 😄).
2. Salve o arquivo como **`tema.mp3`** (o nome precisa ser exatamente esse).
3. Coloque aqui nesta pasta: `public/music/tema.mp3`.
4. Suba no git e pronto — o botão 🎵 vai tocar.

## Observações importantes

- **Formato:** use `.mp3` (funciona em todos os navegadores). Se quiser usar
  outro nome ou formato, me avise que eu ajusto em `app/page.js`.
- **Tamanho:** tente deixar abaixo de ~5 MB pra não pesar. Se a música for
  longa, dá pra cortar um trecho.
- **A música NÃO toca sozinha:** os navegadores (principalmente no celular)
  bloqueiam áudio automático. Por isso o convidado precisa **tocar no botão 🎵**
  pra iniciar. Isso é normal e esperado.
- **Direitos autorais:** como é um site pessoal de convite, o uso é bem
  tranquilo. Só evite divulgar como algo comercial.

## Onde baixar um MP3

Você pode extrair o áudio de um vídeo do YouTube com sites de "YouTube to MP3",
ou usar um trecho de uma música que você já tenha. Depois é só renomear para
`tema.mp3` e subir aqui.
