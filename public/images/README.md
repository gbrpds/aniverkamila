## Trocar uma imagem

Basta substituir o arquivo por outro com o **mesmo nome** (de preferência PNG
com fundo transparente). Para mudar posição/tamanho de um sticker, edite o
componente `<Sticker ... />` correspondente em `app/page.js`.
